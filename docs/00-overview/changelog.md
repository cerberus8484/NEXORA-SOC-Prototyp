# Release Notes

Diese Seite ist die **Docs-Site-Einstiegsseite** für Release-Änderungen in Nexora SOC.
Sie ergänzt die übrige Produkt-Dokumentation um einen schnellen Überblick darüber,
welche größeren Wellen zuletzt umgesetzt wurden.

## Wofür diese Seite da ist

- Sie zeigt die **wichtigsten jüngeren Änderungen** in lesbarer Kurzform.
- Sie ist die **interne Zielseite** für Verweise aus der MkDocs-Site.
- Für den **kanonischen Live-Stand** bleibt die
  [Feature-Status-Matrix](feature-status.md) maßgeblich.

## Aktueller Fokus

### 2026-07

- **Containment Real-Execution** wurde als menschlich ausgelöster, mehrfach gegateter
  Workflow vorbereitet und bleibt standardmäßig inert.
- **Deployment Center** wurde für updatebare Windows- und Linux-Nodes erweitert,
  inklusive Runbook und fail-closed Schutzlogik.
- **Frontend-/nginx-Hardening** wurde um CSP-/HSTS-Validierung und reproduzierbare
  Smoke-Prüfungen ergänzt.
- **Docs-/Wiki-Auslieferung** wurde in die Web-Prüfung aufgenommen und als eigene
  Site-Struktur bereinigt.

### 2026-06

- **Data Plane / Cross-Domain-Korrelation** wurde produktiv verdrahtet.
- **NIS2-Readiness**, **Provisioning-Registry** und große Teile der
  **Enterprise-Security** sind live.
- **CI/E2E/SBOM** wurden produktiv in GitHub Actions verankert.
