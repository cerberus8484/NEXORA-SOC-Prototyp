HUNT-002

Credential Theft

MITRE: T1003.001 · T1558.003 · T1558.004 · T1550.002 · T1003.006  |  Taktik: Credential Access  |  Basis-Konfidenz: 50

Beschreibung

Erkennt Zugriff auf den LSASS-Prozessspeicher zur Extraktion von Credentials (Mimikatz, ProcDump, comsvcs.dll MiniDump), Kerberoasting (TGS-Requests mit schwacher RC4-Verschlüsselung zum Offline-Cracken), AS-REP Roasting (Accounts ohne Kerberos Pre-Auth), Pass-the-Hash (NTLM-Authentifizierung ohne Klartextpasswort) und DCSync (Replikation von Passwort-Hashes direkt vom DC).

Diese Techniken sind nach der initialen Kompromittierung der häufigste nächste Schritt. Ohne valide Credentials kann ein Angreifer keine Lateral Movement oder Privilege Escalation durchführen.

QRadar AQL

LSASS Handle-Anfragen (Event 4656)

SELECT sourceip, username, ProcessName, ObjectName, AccessMask, LogonId
FROM events
WHERE EventID = 4656
  AND ObjectType = 'Process'
  AND ObjectName ILIKE '%lsass%'
  AND AccessMask IN ('0x1010','0x1410','0x1438','0x143a','0x1fffff','0x1f3fff')
  AND username NOT IN ('SYSTEM','LOCAL SERVICE','NETWORK SERVICE')
  AND ProcessName NOT ILIKE '%MsMpEng%'
  AND ProcessName NOT ILIKE '%werfault%'
  AND ProcessName NOT ILIKE '%csrss%'
LAST 24 HOURS

-- Kerberoasting: viele RC4-Service-Tickets von einer IP
SELECT sourceip, username,
       COUNT(*) AS ticket_count,
       UNIQUECOUNT(ServiceName) AS unique_spns
FROM events
WHERE EventID = 4769
  AND TicketEncryptionType = '0x17'
  AND ServiceName NOT LIKE '%$'
  AND ServiceName != 'krbtgt'
GROUP BY sourceip, username
HAVING ticket_count > 5
LAST 1 HOURS

-- DCSync: Replikations-GUIDs von Nicht-DC
SELECT sourceip, username, ObjectDN, Properties
FROM events
WHERE EventID = 4662
  AND (Properties CONTAINS '1131f6aa-9c07-11d1-f79f-00c04fc2dcd2'
    OR Properties CONTAINS '1131f6ad-9c07-11d1-f79f-00c04fc2dcd2')
  AND username NOT LIKE '%$'
  AND username NOT ILIKE '%MSOL_%'
LAST 24 HOURS

Pass-the-Hash (Event 4624)

SELECT sourceip, TargetUserName, WorkstationName,
       LogonType, AuthenticationPackageName
FROM events
WHERE EventID = 4624
  AND LogonType = '3'
  AND AuthenticationPackageName = 'NTLM'
  AND SubjectUserSID = 'S-1-0-0'
  AND TargetUserName NOT LIKE '%$'
  AND TargetUserName != 'ANONYMOUS LOGON'
GROUP BY sourceip, TargetUserName
HAVING COUNT(*) > 3
LAST 1 HOURS

Splunk SPL

-- LSASS ProcessAccess via Sysmon Event 10
index=sysmon EventCode=10 TargetImage="*\\lsass.exe"
| eval suspicious_mask=if(match(GrantedAccess,
    "0x1010|0x1410|0x1438|0x143a|0x1fffff|0x1f3fff"),1,0)
| where suspicious_mask=1
  AND NOT match(SourceImage,"MsMpEng|werfault|wmiprvse|csrss|svchost|lsm")
| eval tool_hint=case(
    match(SourceImage,"(?i)procdump"),"ProcDump",
    match(CommandLine,"(?i)comsvcs"),"comsvcs.dll MiniDump",
    match(SourceImage,"(?i)taskmanager"),"Task Manager Dump",
    match(GrantedAccess,"0x1438|0x143a"),"Mimikatz (typische AccessMask)",
    1==1,"Unbekanntes Tool — manuelle Prüfung")
| table _time, ComputerName, User, SourceImage,
        GrantedAccess, tool_hint, CallTrace

-- Kerberoasting: RC4 Service Tickets
index=wineventlog EventCode=4769 TicketEncryptionType="0x17"
| where ServiceName!="krbtgt"
  AND NOT match(ServiceName,"\\$")
| stats count as ticket_count, values(ServiceName) as targets
  by src_ip, Account_Name, _time span=30m
| where ticket_count > 5
| eval severity=if(ticket_count>20,"CRITICAL","HIGH")

-- AS-REP Roasting: keine Pre-Auth
index=wineventlog EventCode=4768
| where PreAuthType="0"
  AND NOT match(TargetUserName,"\\$")
| stats count by TargetUserName, src_ip, _time span=1h

Sysmon / Windows Security Events

-- Kritische Event IDs
-- Sysmon Event 10: ProcessAccess auf lsass.exe
--   GrantedAccess 0x1438/0x143a = Mimikatz Standard
--   GrantedAccess 0x1fffff      = PROCESS_ALL_ACCESS
--   CallTrace auf UNKNOWN       = kein legitimer Modul-Pfad

-- WinSec Event 4769: Kerberos Service Ticket
--   TicketEncryptionType = 0x17 = RC4-HMAC (Kerberoasting möglich)
--   TicketEncryptionType = 0x12 = AES256   (kein Kerberoasting)

-- WinSec Event 4768: TGT-Anfrage
--   PreAuthType = 0 = KEIN Pre-Auth = AS-REP Roasting möglich

-- WinSec Event 4624: Anmeldung
--   LogonType = 3 + NTLM + SubjectUserSID = S-1-0-0 → Pass-the-Hash

-- WinSec Event 4662: Objekt-Zugriff (DCSync)
--   GUID 1131f6aa = DS-Replication-Get-Changes
--   GUID 1131f6ad = DS-Replication-Get-Changes-All
--   Wenn SubjectUserName kein $ (Computer-Account) → DCSync!

True Positives

  • Mimikatz sekurlsa::logonpasswords (Konfidenz: 98) — GrantedAccess 0x1438 oder 0x143a, CallTrace enthält UNKNOWN-Speicherbereiche, typisch: umbenannte Kopie von mimikatz.exe
  • ProcDump -ma lsass.exe (Konfidenz: 95) — procdump.exe mit -ma Flag auf lsass PID, .dmp-Datei in C:\Users\...\AppData oder C:\Temp
  • comsvcs.dll MiniDump (LOLBin) (Konfidenz: 97) — rundll32.exe C:\Windows\System32\comsvcs.dll, MiniDump <PID> lsass.dmp full
  • Kerberoasting (RC4) (Konfidenz: 85) — Event 4769, EncryptionType=0x17, >5 verschiedene SPNs von einer Workstation innerhalb von 30 Minuten
  • DCSync von Workstation (Konfidenz: 98) — Event 4662 mit DS-Replication GUIDs, SubjectUserName ist kein Computer-Account ($)
  • Pass-the-Hash (NTLM Type 3) (Konfidenz: 80) — Event 4624, LogonType=3, NTLM-Auth, SubjectUserSID=S-1-0-0 von Workstation zu Server

False Positives & Whitelist

  • AV/EDR-Prozesse — CrowdStrike, MsMpEng, SentinelOne, Carbon Black greifen legitim auf LSASS zu. Whitelist: Prozessname aus bekannter AV-Liste
  • WER (Windows Error Reporting) — werfault.exe nach Prozessabsturz, 100% legitim. Whitelist: werfault.exe generell
  • Legitime NTLM-Authentifizierung — Legacy-Systeme, Drucker, ältere Server ohne Kerberos-Support. Whitelist: bekannte Legacy-Hosts
  • DC-zu-DC Replikation — Echte DCs replizieren via Event 4662, SubjectUserName endet auf $. Whitelist: alle Computer-Accounts ($)
  • SQL Server / Exchange Service Accounts — Fordern regelmäßig Service Tickets an. Whitelist: bekannte Service-Account-Liste für Event 4769

Varianten & Evasion-Techniken

  • VAR-001: Nanodump / PPLdump (Conf-Modifier: -10) — Umgeht PPL (Protected Process Light) via Kernel-Treiber. Kein direkter LSASS-Zugriff sichtbar, aber Treiber-Load (Sysmon 6) erkennbar
  • VAR-002: AS-REP Roasting (Conf-Modifier: 0) — Accounts ohne Pre-Auth. Kein Passwort nötig. Event 4768 mit PreAuthType=0. Häufig übersehen
  • VAR-003: Task Manager LSASS-Dump (Conf-Modifier: -25) — Legitimes Windows-Tool. Nur verdächtig wenn non-admin User oder Dump in ungewöhnlichem Pfad
  • VAR-004: Schemaless DCSync (Impacket) (Conf-Modifier: 0) — secretsdump.py von Linux, erscheint als NTLM-Auth von unbekannter IP gegen DC
