HUNT-004

Persistence

MITRE: T1547.001 · T1053.005 · T1543.003 · T1546.003 · T1197  |  Taktik: Persistence  |  Basis-Konfidenz: 55

Beschreibung

Erkennt Mechanismen die einem Angreifer ermöglichen auch nach Neustart oder Credential-Wechsel im System zu bleiben. Registry Run Keys sind der häufigste Weg. Scheduled Tasks werden oft für regelmäßige C2-Verbindungen genutzt.

Neue Services in ungewöhnlichen Pfaden, WMI Subscriptions (schwer zu entdecken) und BITS Jobs sind weitere häufige Techniken.

QRadar AQL

-- Registry Run/RunOnce Writes (Sysmon Event 13)
SELECT sourceip, username, RegistryKey, RegistryValue, RegistryValueData
FROM events
WHERE EventID = 'Microsoft-Windows-Sysmon/Operational:13'
  AND (RegistryKey ILIKE '%\\Run\\%'
    OR RegistryKey ILIKE '%\\RunOnce\\%'
    OR RegistryKey ILIKE '%\\RunOnceEx\\%'
    OR RegistryKey ILIKE '%\\Winlogon\\%'
    OR RegistryKey ILIKE '%\\Userinit\\%'
    OR RegistryKey ILIKE '%\\AppInit_DLLs%')
  AND username NOT IN ('SYSTEM','TrustedInstaller')
LAST 24 HOURS

-- Neue Scheduled Tasks (Event 4698)
SELECT sourceip, username, TaskName, TaskContent
FROM events
WHERE EventID = 4698
  AND (TaskContent ILIKE '%powershell%'
    OR TaskContent ILIKE '%-enc%'
    OR TaskContent ILIKE '%cmd /c%'
    OR TaskContent ILIKE '%wscript%'
    OR TaskContent ILIKE '%mshta%'
    OR TaskContent ILIKE '%AppData%'
    OR TaskContent ILIKE '%Temp%')
  AND username NOT IN ('SYSTEM','Administrator')
LAST 24 HOURS

-- Neue Services (Event 7045)
SELECT sourceip, username, ServiceName, ServiceFileName, ServiceType
FROM events
WHERE EventID = 7045
  AND (ServiceFileName ILIKE '%AppData%'
    OR ServiceFileName ILIKE '%Temp%'
    OR ServiceFileName ILIKE '%Users%Public%'
    OR ServiceFileName ILIKE '%.ps1%'
    OR ServiceFileName ILIKE '%.vbs%')
LAST 24 HOURS

Splunk SPL

-- Registry Persistence via Sysmon Event 13
index=sysmon EventCode=13
| where match(TargetObject,
    "(?i)(\\\\Run\\\\|\\\\RunOnce\\\\|\\\\Winlogon\\\\|\\\\AppInit_DLLs)")
  AND NOT match(User,"(?i)(SYSTEM|TrustedInstaller)")
| eval persistence_type=case(
    match(TargetObject,"(?i)\\\\Run\\\\"),"Registry Run Key",
    match(TargetObject,"(?i)\\\\Winlogon\\\\"),"Winlogon Hijack",
    match(TargetObject,"(?i)AppInit"),"AppInit DLL",
    1==1,"Andere Registry Persistence")
| table _time, ComputerName, User, TargetObject, Details, persistence_type

-- Scheduled Tasks mit verdächtigen Inhalten
index=wineventlog EventCode=4698
| rex field=TaskContent "<Command>(?<cmd>[^<]+)</Command>"
| where match(cmd,"(?i)(powershell|cmd\\.exe|wscript|mshta|AppData|Temp)")
| table _time, ComputerName, SubjectUserName, TaskName, cmd

Sysmon / Windows Security Events

-- Sysmon Event 12/13/14: Registry-Operationen
--   Event 12: Key erstellt/gelöscht
--   Event 13: Wert gesetzt (kritisch für Run-Keys)
--   Event 14: Wert umbenannt

-- Sysmon Event 11: Datei erstellt
--   .job Dateien in C:\Windows\System32\Tasks\
--   → neue Scheduled Tasks

-- WinSec Event 4698: Scheduled Task erstellt
-- WinSec Event 4702: Scheduled Task geändert
-- WinSec Event 7045: Neuer Service

-- WMI Subscriptions (schwer zu erkennen):
--   Get-WMIObject -Namespace root\subscription -Class __EventFilter
--   Get-WMIObject -Namespace root\subscription -Class __EventConsumer
--   Sysmon Event 19/20/21 für WMI Activity

True Positives

  • Registry HKCU\...\Run\evil = C:\Users\...\AppData\Roaming\malware.exe (Konfidenz: 85)
  • Scheduled Task mit -enc Base64 PowerShell jeden 5 Minuten (Konfidenz: 90)
  • Neuer Service aus C:\Users\...\AppData\Local\Temp (Konfidenz: 88)
  • WMI EventFilter + EventConsumer Subscription (Konfidenz: 92)
  • BITS Job der alle 30min eine URL herunterlädt (Konfidenz: 75)

False Positives & Whitelist

  • Software-Installer — Legitimate Installer schreibt Run-Keys. Whitelist: bekannte Software-Hashes
  • Windows Update — schreibt Tasks in C:\Windows\System32\Tasks. Whitelist: SYSTEM + bekannte Task-Namen
  • AV/EDR — erstellt eigene Services. Whitelist: bekannte AV-Prozesse
  • Backup Software — erstellt Tasks für Backup-Zeitpläne. Whitelist: Backup-Prozesse

Varianten & Evasion-Techniken

  • VAR-001: COM Object Hijacking (Conf-Modifier: -20) — Registry HKCU\Software\Classes\CLSID\ überschreibt System-COM — sehr schwer zu erkennen
  • VAR-002: Accessibility Features (Conf-Modifier: -5) — sethc.exe oder utilman.exe durch cmd.exe ersetzen (Event 4656 auf System32-Dateien)
  • VAR-003: Boot Execute (Conf-Modifier: -10) — HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\BootExecute
  • VAR-004: PowerShell Profile (Conf-Modifier: -15) — $PROFILE Datei mit Backdoor-Code
