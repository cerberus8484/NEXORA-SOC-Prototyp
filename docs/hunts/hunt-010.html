HUNT-010

Initial Access / Phishing

MITRE: T1566.001 · T1204.002 · T1059 · T1553.005  |  Taktik: Initial Access  |  Basis-Konfidenz: 65

Beschreibung

Erkennt den ersten Fuß in der Tür: Office-Dokumente die cmd.exe oder PowerShell spawnen (Makro-Ausführung), Browser die ungewöhnliche Kind-Prozesse erzeugen (Drive-by Download), .lnk-Dateien aus dem Downloads-Ordner die Prozesse starten, HTA-Dateien aus E-Mail-Anhängen und ISO/IMG-Mounts mit anschließender LNK-Ausführung (moderner Phishing-Bypass für Mark-of-the-Web).

Parent-Child-Prozessbeziehungen sind das Kernmerkmal dieses Hunts. Ein Office-Prozess der eine Shell erzeugt oder ein Browser der cmd.exe startet ist in legitimen Umgebungen nahezu nie erwartet. ISO-basiertes Phishing umgeht Mark-of-the-Web, da gemountete Volumes keine Zone-Identifier erben — dieser Vektor erfordert spezielle Aufmerksamkeit.

QRadar AQL

Office-Anwendungen spawnen verdächtige Prozesse (Makro-Ausführung)

-- Office-Anwendungen spawnen verdächtige Prozesse (Makro-Ausführung)
SELECT sourceip, username, ProcessName, CommandLine, ParentProcessName
FROM events
WHERE EventID = 4688
  AND ParentProcessName IN (
    'WINWORD.EXE','EXCEL.EXE','POWERPNT.EXE',
    'OUTLOOK.EXE','MSPUB.EXE','VISIO.EXE',
    'winword.exe','excel.exe','powerpnt.exe'
  )
  AND ProcessName IN (
    'cmd.exe','powershell.exe','wscript.exe',
    'cscript.exe','mshta.exe','rundll32.exe',
    'regsvr32.exe','certutil.exe'
  )
LAST 24 HOURS

-- Browser spawnen ungewöhnliche Kind-Prozesse
SELECT sourceip, username, ProcessName, CommandLine, ParentProcessName
FROM events
WHERE EventID = 4688
  AND ParentProcessName IN (
    'chrome.exe','msedge.exe','firefox.exe',
    'iexplore.exe','brave.exe','opera.exe'
  )
  AND ProcessName IN (
    'cmd.exe','powershell.exe','wscript.exe',
    'cscript.exe','mshta.exe','explorer.exe'
  )
  AND CommandLine NOT ILIKE '%chrome%'
  AND CommandLine NOT ILIKE '%update%'
LAST 24 HOURS

-- Ausführung aus Downloads/Temp (User hat Datei ausgeführt)
SELECT sourceip, username, ProcessName, CommandLine, CurrentDirectory
FROM events
WHERE EventID = 4688
  AND (CurrentDirectory ILIKE '%Downloads%'
    OR CurrentDirectory ILIKE '%Temp%'
    OR CurrentDirectory ILIKE '%AppData%Local%Temp%')
  AND ProcessName IN (
    'cmd.exe','powershell.exe','wscript.exe',
    'cscript.exe','mshta.exe','regsvr32.exe'
  )
LAST 24 HOURS

Splunk SPL

-- Office-Makro Ausführung: Parent-Child Process Chain
index=sysmon EventCode=1
| eval office_spawn=if(
    match(ParentImage,"(?i)(winword|excel|powerpnt|outlook|mspub)\\.exe")
    AND match(Image,"(?i)(cmd|powershell|wscript|cscript|mshta|rundll32)\\.exe"),1,0)
| where office_spawn=1
| eval macro_score=case(
    match(CommandLine,"(?i)-enc|-encodedcommand"), 95,
    match(CommandLine,"(?i)DownloadString|DownloadFile|WebClient"), 90,
    match(CommandLine,"(?i)http|ftp"), 80,
    match(Image,"(?i)powershell\\.exe"), 70,
    1==1, 60)
| table _time, ComputerName, User, ParentImage, Image, CommandLine, macro_score

-- LNK-Ausführung aus Downloads
index=sysmon EventCode=1
| where match(ParentImage,"(?i)explorer\\.exe")
  AND (match(CommandLine,"(?i)(Downloads|Desktop|Temp|AppData)")
       OR match(ParentCommandLine,"(?i)\\.lnk"))
  AND match(Image,"(?i)(cmd|powershell|wscript|mshta)\\.exe")
| table _time, ComputerName, User, Image, CommandLine, ParentCommandLine

-- ISO/IMG Mount + Ausführung (moderner Phishing-Bypass)
index=sysmon EventCode=1
| where match(Image,"(?i)(cmd|powershell|wscript|rundll32)\\.exe")
  AND match(CurrentDirectory,"[A-Z]:\\\\$")
| stats count by ComputerName, User, Image, CommandLine, _time span=5m
| eval iso_exec_likely=if(
    match(CommandLine,"(?i)(Downloads|Desktop)"), 1, 0)

Sysmon / Windows Security Events

-- Sysmon Event 1: Prozess-Erstellung
-- Parent-Child-Beziehungen sind der Schlüssel:

-- OFFICE → SHELL:
--   winword.exe → cmd.exe     = Makro
--   excel.exe   → powershell  = Makro
--   outlook.exe → wscript.exe = E-Mail-Anhang-Ausführung

-- BROWSER → SHELL:
--   chrome.exe  → cmd.exe    = Drive-by
--   msedge.exe  → powershell = Drive-by

-- ISO/IMG Mount Pattern:
--   Neues Laufwerk gemountet (kein echtes DVD-Laufwerk)
--   explorer.exe spawnt Prozess aus Root des gemounteten Laufwerks
--   Mark-of-the-Web wird NICHT vererbt!

-- LNK aus E-Mail/Downloads:
--   explorer.exe spawnt cmd.exe mit Working Dir = Downloads
--   Commandline-Argument enthält .lnk Pfad

-- HTML Smuggling:
--   Browser erstellt .exe/.iso Datei in Downloads (Sysmon 11)
--   Kurz danach: explorer.exe öffnet die Datei (Sysmon 1)

True Positives

  • winword.exe spawnt powershell.exe mit -enc Base64 (Konfidenz: 95) — Makro lädt encoded PowerShell-Payload nach. Klassisches Muster für Phishing-Dokument mit Downloader-Makro
  • excel.exe spawnt cmd.exe mit DownloadString-URL (Konfidenz: 93) — Makro lädt Payload via WebClient direkt nach. Kein legitimes Excel-Verhalten
  • chrome.exe spawnt cmd.exe (kein Chrome-eigener Prozess) (Konfidenz: 85) — Drive-by Download oder Browser-Exploit. Browser-Kind-Prozesse sollten ausschließlich Chrome-eigene Prozesse sein
  • explorer.exe spawnt wscript.exe aus Downloads-Ordner .lnk (Konfidenz: 88) — User hat .lnk-Datei aus Downloads ausgeführt. Working Directory = Downloads ist starkes Indiz
  • mshta.exe von outlook.exe als Parent (Konfidenz: 92) — HTA-Datei direkt aus E-Mail-Anhang. mshta.exe als Outlook-Kind ist nahezu immer bösartig
  • ISO gemountet → LNK → cmd.exe (Mark-of-the-Web-Bypass) (Konfidenz: 85) — Prozess startet aus Root eines gemounteten ISO-Laufwerks. Kein Zone-Identifier vererbt

False Positives & Whitelist

  • Legitime Office-Makros für Geschäftsprozesse — Whitelist: bekannte Makro-Hashes oder durch Gruppenrichtlinie signierte Makros aus vertrauenswürdigen Quellen
  • IT-Admin die legitime Scripts via PS starten — Admins starten gelegentlich PowerShell aus Office-Vorlagen oder Management-Skripten. Whitelist: Admin-Workstations
  • Software-Updates die Browser-Updates als Kind-Prozess haben — Einige Update-Mechanismen laufen als Browser-Kind. Whitelist: Update-Prozesse mit bekannten Commandlines und signierten Binaries

Varianten & Evasion-Techniken

  • VAR-001: XLL Add-in Execution (Conf-Modifier: -10) — Excel lädt .xll Plugin das Code ausführt. Neuerer Angriffsvektor (2022+), kein klassisches Makro sondern nativer Code-Einstiegspunkt
  • VAR-002: OneNote Embedded Script (Conf-Modifier: -15) — .one Datei mit eingebettetem .bat oder .exe, 2023 häufig genutzt als Makro-Ersatz nach Microsoft-Härtung. OneNote.exe als Parent
  • VAR-003: HTML Smuggling (Conf-Modifier: -20) — JavaScript erstellt Datei im Browser-Speicher und lädt sie in Downloads. Kein direkter Parent-Prozess zwischen Payload und Browser sichtbar
  • VAR-004: Template Injection (Conf-Modifier: -15) — Word lädt Remote-Template nach, kein lokales Makro. Netzwerkverbindung von winword.exe zu externem Host unmittelbar nach Öffnen des Dokuments
