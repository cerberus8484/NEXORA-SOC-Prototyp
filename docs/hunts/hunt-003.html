HUNT-003

Lateral Movement

MITRE: T1021.002 · T1021.006 · T1047 · T1021.001 · T1570  |  Taktik: Lateral Movement  |  Basis-Konfidenz: 45

Beschreibung

Erkennt seitliche Bewegung im Netzwerk durch bekannte Techniken: PsExec (Service PSEXESVC wird auf Ziel installiert), WMI Remote Execution (wmiprvse.exe spawnt verdächtige Prozesse), SMB Admin Share Zugriff, RDP von ungewöhnlichen Quellen, WinRM/PowerShell Remoting.

Ein Angreifer nutzt Lateral Movement um von einem kompromittierten Endpoint zu weiteren Systemen zu gelangen.

QRadar AQL

-- PsExec: Service PSEXESVC wird auf Ziel installiert
SELECT sourceip, destinationip, username, ServiceName, ServiceFileName
FROM events
WHERE EventID = 7045
  AND (ServiceName = 'PSEXESVC'
    OR ServiceFileName ILIKE '%psexec%'
    OR ServiceFileName ILIKE '%paexec%'
    OR ServiceFileName ILIKE '%remcom%')
LAST 24 HOURS

-- Laterale NTLM-Bewegung: Logon Type 3 von Workstations
SELECT sourceip, destinationip, TargetUserName,
       LogonType, AuthenticationPackageName
FROM events
WHERE EventID = 4624
  AND LogonType = '3'
  AND AuthenticationPackageName = 'NTLM'
  AND sourceip NOT INCIDR '127.0.0.0/8'
  AND destinationip NOT INCIDR '127.0.0.0/8'
  AND sourceip NOT IN (SELECT ip FROM reference_set:'Domain Controllers')
GROUP BY sourceip, destinationip, TargetUserName
HAVING COUNT(*) > 3
LAST 1 HOURS

Splunk SPL

-- WMI Remote Execution: wmiprvse spawnt verdächtige Prozesse
index=sysmon EventCode=1
| where match(ParentImage,"(?i)wmiprvse\\.exe")
  AND match(Image,"(?i)(cmd\\.exe|powershell\\.exe|wscript\\.exe|cscript\\.exe|mshta\\.exe)")
| table _time, ComputerName, User, Image, CommandLine, ParentImage, ParentCommandLine

-- RDP von ungewöhnlichen Quellen (LogonType 10)
index=wineventlog EventCode=4624 Logon_Type=10
| where NOT match(src_ip,"^(10\\.|172\\.(1[6-9]|2[0-9]|3[01])\\.|192\\.168\\.)")
    OR (match(src_ip,"^192\\.168\\.") AND NOT src_ip IN (known_admin_ips))
| stats count by src_ip, TargetUserName, ComputerName, _time span=1h
| where count > 1

Sysmon / Windows Security Events

-- Sysmon Event 1: Prozess-Erstellung
-- PsExec-Indikatoren:
--   ParentImage = services.exe (Service-Start)
--   Image = cmd.exe oder powershell.exe
--   CommandLine enthält \\PSEXESVC oder \\pipe\\

-- WMI Remote:
--   ParentImage = wmiprvse.exe spawnt cmd/ps/wscript

-- WinRM / PowerShell Remoting:
--   ParentImage = wsmprovhost.exe spawnt beliebige Prozesse
--   EventID 4624 LogonType=3 von Remote-IP

-- Admin Share Access:
--   EventID 5140: Netzwerkfreigabe \\ADMIN$ oder \\C$
--   von unbekannten IPs

True Positives

  • PsExec: PSEXESVC Service + 4624 LogonType 3 + SMB Traffic (Konfidenz: 90)
  • WMI Remote Execution: wmiprvse.exe spawnt cmd.exe mit remote Commandline (Konfidenz: 85)
  • RDP von Workstation zu Workstation, kein Admin-Host (Konfidenz: 75)
  • Admin Share Zugriff (\\HOST\ADMIN$) von unbekannter IP (Konfidenz: 70)
  • WinRM: wsmprovhost.exe spawnt PowerShell mit Import-Module (Konfidenz: 80)

False Positives & Whitelist

  • SCCM/Intune Software Deployment — Service-Installation von bekannten Management-IPs. Whitelist: SCCM-Server IPs
  • Helpdesk RDP — RDP von Helpdesk-Workstations. Whitelist: Helpdesk-IP-Range
  • Monitoring Agents — WMI-Abfragen von Monitoring-Server. Whitelist: Monitoring-Server
  • Backup Software — Admin Share Zugriff von Backup-Server. Whitelist: Backup-Server IP

Varianten & Evasion-Techniken

  • VAR-001: Renamed PsExec (Conf-Modifier: -15) — Umbenennen von psexec.exe, aber PSEXESVC Service-Name bleibt gleich
  • VAR-002: DCOM Execution (Conf-Modifier: -10) — Lateral Movement via DCOM, wmiprvse.exe oder svchost spawnt Prozess
  • VAR-003: SCM Remote Service (Conf-Modifier: -5) — sc.exe \\remote create/start ohne PsExec
  • VAR-004: Pass-the-Ticket RDP (Conf-Modifier: 0) — Kerberos-Ticket für RDP gestohlen, erscheint als legitime Kerberos-Auth
