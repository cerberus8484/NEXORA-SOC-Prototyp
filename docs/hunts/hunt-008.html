HUNT-008

Privilege Escalation

MITRE: T1134.001 · T1548.002 · T1574.001 · T1574.002  |  Taktik: Privilege Escalation  |  Basis-Konfidenz: 55

Beschreibung

Erkennt Techniken um lokale Admin- oder SYSTEM-Rechte zu erlangen: Token Impersonation (SeImpersonatePrivilege-Missbrauch via JuicyPotato/PrintSpoofer), UAC-Bypass (Umgehung der Benutzerkontensteuerung ohne Admin-Dialog), DLL Hijacking (verdächtige DLL vor System32 in Suchpfad), AlwaysInstallElevated (MSI mit SYSTEM-Rechten).

Diese Techniken werden nach initialer Kompromittierung genutzt um von Standard-User zu Admin/SYSTEM zu gelangen. Besonderes Augenmerk gilt der zeitlichen Korrelation mit vorherigen Kompromittierungsindikatoren.

QRadar AQL

UAC Bypass & Prozesse mit erhöhten Privilegien

-- UAC Bypass via fodhelper.exe
SELECT sourceip, username, ProcessName, CommandLine, ParentProcessName
FROM events
WHERE EventID = 4688
  AND ParentProcessName ILIKE '%fodhelper%'
  AND ProcessName IN ('cmd.exe','powershell.exe','wscript.exe','cscript.exe')
LAST 24 HOURS

-- UAC Bypass via eventvwr.exe
SELECT sourceip, username, ProcessName, ParentProcessName
FROM events
WHERE EventID = 4688
  AND ParentProcessName ILIKE '%eventvwr%'
  AND ProcessName NOT IN ('mmc.exe','wbem\wmiprvse.exe')
LAST 24 HOURS

-- Prozess mit ungewöhnlichen Privilegien
SELECT sourceip, username, ProcessName, TokenElevationType, Privileges
FROM events
WHERE EventID = 4688
  AND TokenElevationType = '%%1937'
  AND Privileges ILIKE '%SeDebugPrivilege%'
  AND ProcessName NOT IN (
    'C:\Windows\System32\lsass.exe',
    'C:\Windows\System32\services.exe',
    'C:\Program Files\...'
  )
LAST 24 HOURS

-- AlwaysInstallElevated: MSI-Ausführung
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND ProcessName ILIKE '%msiexec%'
  AND CommandLine ILIKE '%/quiet%'
  AND CommandLine ILIKE '%.msi%'
  AND username NOT IN ('SYSTEM','Administrator')
  AND ParentProcessName NOT ILIKE '%svchost%'
LAST 24 HOURS

Splunk SPL

-- UAC Bypass Erkennungsmuster
index=sysmon EventCode=1
| eval uac_bypass=case(
    match(ParentImage,"(?i)fodhelper\\.exe") AND match(Image,"(?i)(cmd|powershell)\\.exe"),"fodhelper UAC Bypass",
    match(ParentImage,"(?i)eventvwr\\.exe") AND NOT match(Image,"(?i)(mmc|wmiprvse)\\.exe"),"eventvwr UAC Bypass",
    match(ParentImage,"(?i)sdclt\\.exe") AND match(Image,"(?i)cmd\\.exe"),"sdclt UAC Bypass",
    match(ParentImage,"(?i)cmstp\\.exe"),"CMSTP UAC Bypass",
    1==1,null())
| where isnotnull(uac_bypass)
| table _time, ComputerName, User, Image, CommandLine, uac_bypass

-- DLL Hijacking: DLL aus User-Verzeichnis geladen
index=sysmon EventCode=7
| where match(ImageLoaded,"(?i)(AppData|Temp|Users\\\\Public|Downloads)")
  AND match(Image,"(?i)(C:\\\\Windows\\\\System32|C:\\\\Program Files)")
  AND NOT match(Signed,"true")
| table _time, ComputerName, Image, ImageLoaded, Signed, Company

-- SeImpersonatePrivilege Missbrauch
index=sysmon EventCode=1
| where match(CommandLine,"(?i)(JuicyPotato|PrintSpoofer|RoguePotato|SweetPotato)")
    OR (match(IntegrityLevel,"(?i)system") AND match(ParentImage,"(?i)services\\.exe")
        AND match(User,"(?i)(network service|local service|iis apppool)"))

Sysmon / Windows Security Events

-- Sysmon Event 7: Image Loaded (DLL Hijacking)
--   Signierte Systemanwendung lädt unsignierte DLL
--   DLL-Pfad in user-kontrollierbarem Verzeichnis
--   Vor System32-Version im Suchpfad gefunden

-- Sysmon Event 1: Prozess-Erstellung (UAC Bypass)
--   fodhelper.exe spawnt elevated cmd.exe/powershell.exe
--   eventvwr.exe spawnt ungewöhnliche Prozesse
--   Integrity Level = High ohne UAC-Dialog

-- WinSec Event 4688: Prozess mit hohen Privilegien
--   TokenElevationType = %%1937 = Full Token (elevated)
--   SeDebugPrivilege für Nicht-Admin-Prozesse

-- Registry Indikatoren für UAC Bypass:
--   HKCU\Software\Classes\ms-settings\shell\open\command
--   (wird von fodhelper/sdclt gelesen und UAC-frei ausgeführt)
--   Sysmon Event 13: Write auf diesen Key von nicht-Admin

True Positives

  • fodhelper.exe spawnt cmd.exe elevated (Konfidenz: 90) — fodhelper.exe liest HKCU\...\ms-settings\shell\open\command und führt Inhalt mit hohem Integrity Level aus
  • eventvwr.exe spawnt PowerShell.exe mit high Integrity Level (Konfidenz: 88) — eventvwr UAC Bypass via HKCU-Registry-Hijack, PowerShell startet ohne UAC-Dialog als elevated
  • JuicyPotato/PrintSpoofer Commandline erkannt (Konfidenz: 95) — Toolname in CommandLine oder Image, Token-Impersonation via Named Pipe, Zielprozess läuft als SYSTEM
  • Unsignierte DLL aus AppData von System32-Prozess geladen (Konfidenz: 75) — Sysmon Event 7, Signed=false, Pfad in user-kontrollierbarem Verzeichnis vor System32 im DLL-Suchpfad
  • HKCU\...\ms-settings\shell\open\command geschrieben + fodhelper danach (Konfidenz: 92) — Zeitliche Korrelation: Registry-Write (Sysmon 13) gefolgt von fodhelper.exe-Start innerhalb von 60 Sekunden

False Positives & Whitelist

  • Legitime elevated Prozesse durch Admin (echte UAC-Zustimmung) — IntegrityLevel High nach echtem UAC-Dialog erkennbar an ParentProcess consent.exe. Kontext: Elevation via consent.exe schließt UAC-Bypass aus
  • Software-Installation durch Admin — Legitime Installer starten elevated mit bekanntem Signatur-Zertifikat. Whitelist: bekannte Installer-Hashes + Admin-Kontext + Ticket-Nachweis
  • Entwicklungstools die DLLs aus AppData laden — IDEs wie Visual Studio oder JetBrains laden eigene DLLs aus AppData. Whitelist: bekannte IDE-Prozesse mit valider Signatur des Vendors

Varianten & Evasion-Techniken

  • VAR-001: RoguePotato / SweetPotato (Conf-Modifier: -5) — Neuere Token-Impersonation-Tools mit ähnlichen Indicators wie JuicyPotato. Named-Pipe-basiert, Erkennung über Prozessname oder CLSID-Lookup
  • VAR-002: CMSTP UAC Bypass (Conf-Modifier: -10) — cmstp.exe lädt INF-Datei und spawnt elevated Prozess. Weniger bekannt, ParentImage cmstp.exe als Indikator
  • VAR-003: DiskCleanup UAC Bypass (Conf-Modifier: -15) — cleanmgr.exe DLL Hijacking via SilentCleanupTask in System32-Suchpfad, Task läuft elevated ohne UAC-Dialog
  • VAR-004: Mock Trusted Directories (Conf-Modifier: -20) — C:\Windows \ (mit Leerzeichen) imitiert System32-Pfad um UAC-Prüfung zu umgehen, sehr schwer ohne Pfad-Normalisierung erkennbar
