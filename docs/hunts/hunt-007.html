HUNT-007

Ransomware Precursors

MITRE: T1490 · T1486 · T1489 · T1562.001  |  Taktik: Impact  |  Basis-Konfidenz: 70

Beschreibung

Ransomware-Angreifer bereiten die Verschlüsselung systematisch vor: Volume Shadow Copies werden gelöscht (kein Recovery möglich), Backup-Prozesse gestoppt, Recovery-Optionen deaktiviert, AV/EDR deaktiviert. Diese Vorbereitungsschritte laufen typischerweise 15–60 Minuten vor der eigentlichen Verschlüsselung ab.

Früherkennung in dieser Phase kann die Verschlüsselung verhindern. Sobald 3 oder mehr Indikatoren gleichzeitig auftreten, ist ein sofortiger Alarm erforderlich.

QRadar AQL

Volume Shadow Copy Deletion

-- Volume Shadow Copy Deletion
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND (
    (ProcessName ILIKE '%vssadmin%' AND CommandLine ILIKE '%delete shadows%')
    OR (ProcessName ILIKE '%wmic%' AND CommandLine ILIKE '%shadowcopy delete%')
    OR (ProcessName ILIKE '%wbadmin%' AND CommandLine ILIKE '%delete catalog%')
    OR (ProcessName ILIKE '%bcdedit%' AND
        (CommandLine ILIKE '%recoveryenabled no%'
          OR CommandLine ILIKE '%bootstatuspolicy ignoreallfailures%'))
  )
LAST 24 HOURS

-- Backup-Prozesse stoppen
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND ProcessName ILIKE '%net%'
  AND CommandLine ILIKE '%stop%'
  AND (
    CommandLine ILIKE '%veeam%'
    OR CommandLine ILIKE '%backup%'
    OR CommandLine ILIKE '%sql%'
    OR CommandLine ILIKE '%exchange%'
    OR CommandLine ILIKE '%acronis%'
  )
LAST 1 HOURS

-- AV/Defender deaktivieren
SELECT sourceip, username, ProcessName, CommandLine
FROM events
WHERE EventID = 4688
  AND (
    CommandLine ILIKE '%Set-MpPreference -DisableRealtimeMonitoring%'
    OR CommandLine ILIKE '%sc stop WinDefend%'
    OR CommandLine ILIKE '%taskkill%MsMpEng%'
    OR CommandLine ILIKE '%taskkill%avp%'
    OR CommandLine ILIKE '%taskkill%kavlauncher%'
  )
LAST 1 HOURS

Splunk SPL

-- Kombinierter Ransomware-Precursor Score
index=sysmon EventCode=1
| eval indicator=case(
    match(Image,"(?i)vssadmin\\.exe") AND match(CommandLine,"(?i)delete shadows"),"VSS_DELETE",
    match(Image,"(?i)wmic\\.exe") AND match(CommandLine,"(?i)shadowcopy.*delete"),"WMI_VSS_DELETE",
    match(Image,"(?i)bcdedit\\.exe") AND match(CommandLine,"(?i)recoveryenabled.*no"),"RECOVERY_DISABLE",
    match(Image,"(?i)wbadmin\\.exe") AND match(CommandLine,"(?i)delete.*catalog"),"BACKUP_DELETE",
    match(Image,"(?i)net\\.exe|net1\\.exe") AND match(CommandLine,"(?i)stop.*(veeam|backup|sql)"),"BACKUP_STOP",
    match(Image,"(?i)taskkill\\.exe") AND match(CommandLine,"(?i)(MsMpEng|avp|kavlauncher)"),"AV_KILL",
    1==1,null())
| where isnotnull(indicator)
| stats count as indicator_count, values(indicator) as indicators
  by ComputerName, User, _time span=30m
| where indicator_count >= 2
| eval ransomware_score=case(
    indicator_count >= 4, 95,
    indicator_count >= 3, 85,
    indicator_count >= 2, 70,
    1==1, 50)
| sort -ransomware_score

-- Massen-Dateioperationen (Verschlüsselung läuft)
index=sysmon EventCode=11
| stats count as file_ops, dc(TargetFilename) as unique_files
  by ComputerName, Image, _time span=1m
| where file_ops > 100
| eval ext_changes=if(match(TargetFilename,"\\.(encrypted|locked|crypted|pays|ransom)$"),1,0)

Sysmon / Windows Security Events

-- Kritische Indikatoren für Ransomware-Vorbereitung:

-- 1. VSS-Deletion (meistens erstes Zeichen):
--    vssadmin.exe delete shadows /all /quiet
--    wmic shadowcopy delete

-- 2. Recovery deaktivieren:
--    bcdedit /set {default} recoveryenabled No
--    bcdedit /set {default} bootstatuspolicy ignoreallfailures

-- 3. Backup-Stop:
--    net stop "Veeam Backup Service"
--    net stop SQLWriter
--    taskkill /im veeam.backup.manager.exe /f

-- 4. Firewall/AV deaktivieren:
--    netsh advfirewall set allprofiles state off
--    Set-MpPreference -DisableRealtimeMonitoring $true

-- 5. Massen-Umbenennung (Verschlüsselung aktiv):
--    Sysmon Event 11: viele .txt/.docx etc. → .encrypted
--    > 100 Dateioperationen pro Minute von einem Prozess

-- WARNUNG: Wenn 3+ Indikatoren gleichzeitig → SOFORTIGER ALARM

True Positives

  • vssadmin delete shadows /all /quiet (Konfidenz: 95) — Direkter VSS-Löschbefehl, kein legitimer Anwendungsfall außerhalb von Backup-Software mit bekanntem Prozesskontext
  • bcdedit /set recoveryenabled no + wbadmin delete catalog (Konfidenz: 98) — Kombination aus Recovery-Deaktivierung und Backup-Katalog-Löschung innerhalb kurzer Zeit
  • net stop "Veeam" + taskkill MsMpEng + vssadmin (3 Indikatoren) (Konfidenz: 99) — Drei Indikatoren gleichzeitig, klassisches Ransomware-Playbook
  • >100 Datei-Renames pro Minute von unbekanntem Prozess (Konfidenz: 90) — Sysmon Event 11, Massendateioperation auf Dateifreigaben oder lokalen Laufwerken
  • AV deaktiviert + Backup gestoppt im selben 5-Minuten-Fenster (Konfidenz: 95) — Zeitliche Korrelation zweier Vorbereitungsschritte erhöht Konfidenz deutlich

False Positives & Whitelist

  • Legitime Backup-Software die VSS Snapshots verwaltet — Veeam und Acronis verwalten VSS-Snapshots im Rahmen normaler Backup-Jobs. Whitelist: Backup-Prozesse mit bekannten Hashes und geplanten Ausführungszeiten
  • IT-Admin deaktiviert Recovery-Optionen für Tests — Vorkommen bei Disaster-Recovery-Tests. Whitelist: Admin-Host + Ticket-Nachweis als Korrelationsbedingung
  • AV-Update startet eigenen Service neu — Vendor-eigene Prozesse können kurzzeitig den Schutzstatus unterbrechen. Whitelist: Vendor-Prozesse mit gültiger digitaler Signatur

Varianten & Evasion-Techniken

  • VAR-001: WMI-basierte VSS-Deletion (Conf-Modifier: 0) — Get-WmiObject Win32_ShadowCopy | Remove-WmiObject — kein vssadmin.exe Prozess sichtbar, Erkennung nur über WMI-Aktivitätslogs möglich
  • VAR-002: PowerShell für alle Schritte (Conf-Modifier: -5) — Scriptblock-basiert, kein eigenständiger Prozess pro Aktion. ScriptBlock-Logging (Event 4104) erforderlich für Erkennung
  • VAR-003: Löschen über Volume Mount (Conf-Modifier: -20) — Shadow Copies via Volume-Mount-Point-Manipulierung gelöscht, kein klassischer Löschbefehl erkennbar
