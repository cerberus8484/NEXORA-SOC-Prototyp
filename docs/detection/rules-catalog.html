4. Brute Force & Password Spray Detection (Rules 101000–101004)

Diese Regeln detektieren Brute-Force sowie Password-Spray-Angriffe durch Aggregation von Authentifizierungs-Fehlern.

Rule ID Level Erkennt MITRE Beschreibung
101000 10 Brute Force: 8+ Logon Failures in 120s, gleiche IP + Account T1110.001 Zyklische Passwort-Attacke auf einen Account. 8+ Fehlversuche in 120 Sekunden.
101001 12 Password Spray: Failures gegen mehrere Accounts von einer IP T1110.003 Horizontal-Angriff: Wenige Passwörter gegen viele Accounts. >5 verschiedene Accounts in kurzer Zeit.
101002 10 Account Lockout: Konto nach Failure-Flood gesperrt T1110 Event 4740 — Konto vom System nach zu vielen Fehlern gesperrt. Deutet auf erfolgreiche Brute-Force hin.
101003 8 Remote Logon Failure: Fehlgeschlagener Network-Logon T1110 Event 4625 mit Logon Type 3/10 — Passwort-Fehler von Remote-Host (RDP, SSH, Kerberos).

NTLM Downgrade & Pass-the-Hash (Rules 101100–101102)

Rule ID Level Erkennt MITRE Beschreibung
101100 12 NTLMv1 Authentication: Downgrade oder Legacy-System T1557.002 NTLMv1 ist kryptographisch schwach und kann leicht offline-gebrochen werden. Zeichen für Downgrade-Angriff.
101101 14 Pass-the-Hash: NTLM mit KeyLength=0 T1550.002 KeyLength=0 bei Network-Logon = direkte Hash-Authentifizierung (PTH). Sehr verdächtig.
101102 10 Anonymous NTLM Login: Null-Session / Recon T1135 Event 4624 mit UserName "ANONYMOUS" — unbenutzter Logon für Netzwerk-Recon.

Kerberos Attacks (Rules 101200–101204)

Erfordert: DC01 & WEC01 mit Windows Event Forwarding (Events 4768, 4769, 4662)

Rule ID Level Erkennt MITRE Beschreibung
101200 14 Kerberoasting: RC4 Service-Ticket für Service-Account T1558.003 Event 4769 mit EncryptionType 0x17 (RC4). RC4 ist einfach zu cracken — Service-Account-Hashes gefährdet.
101201 14 AS-REP Roasting: Pre-Auth deaktiviert auf User T1558.004 Event 4768 mit PreAuthType=0. User ohne PREAUTHENTICATION-Flag: TGT kann offline-gebrochen werden.
101202 15 Golden Ticket: krbtgt RC4-Ticket-Anfrage T1558.001 Event 4768 mit RC4-Encryption für krbtgt. KRITISCH — Attacker mit krbtgt-Hash kann beliebig Tickets erzeugen.
101203 15 DCSync / Credential Dump: Replikationsrechte von Non-DC T1003.006 Event 4662 Directory-Service-Access. Non-DC versucht Directory-Datenbank zu synchronisieren — alle Hashes gefährdet.
101204 14 Silver Ticket: RC4 Service-Ticket ohne TGT-Flow T1558.002 Event 4769 mit verdächtigem Ticket-Alter. Attacker mit Service-Hash kann forged Tickets ausstellen.

Active Directory & Account Management (Rules 101301–101308)

Erfordert: WEC01 mit Event-Forwarding von DC01

Rule ID Level Erkennt MITRE Beschreibung
101301 8 Benutzerkonto erstellt: Neuer User in AD T1136.001 Event 4720 oder 5137. Neue Accounts sind häufig legitim, sollten aber auditiert werden.
101302 5 Konto-Änderung: Aktiviert/deaktiviert/PW-Reset/gelöscht T1098.002 Event 4722/4723/4725. Häufige AD-Admin-Operationen — Level 5 aber archiviert für Audit-Trail (DSGVO).
101303 10 Mitglied zu Gruppe hinzugefügt: User zu Security-Group T1098.004 Event 4728, 4732, 4756. Normal-Operationen, aber archiviert für Privilege-Escalation-Analyse.
101304 13 Zu PRIVILEGIERTER Gruppe hinzugefügt: Admin/Domain Admins T1098.004 Event 4728 zu Domain Admins/Enterprise Admins. Level 13 = High — direkte Privilege-Escalation, sofort reviewen.
101305 8 Account Lockout: Konto gesperrt nach Failures T1110 Event 4740. Kann auf Brute-Force oder legitimen Fehler hindeuten — zur Korrelation mit 101000–101003 nutzen.
101306 13 Security-Audit-Log GELÖSCHT: Admin löscht Log-Einträge T1070.001 Event 1102. Spurenbeseitigung: Sehr verdächtig — aktiver Angriff oder IR-Versuch.
101307 12 Audit-Policy geändert: Audit-Einstellungen modifiziert T1562.002 Event 4719. Impair Defenses: Attacker könnte Audit für bestimmte Events ausschalten.
101308 12 Group-Policy-Objekt (GPO) geändert: GPO modifiziert T1484.001 Event 5136. Domain Policy Manipulation: GPO-Änderungen können Netzwerk-Sicherheit umgehen.

5. Integrationen & AV-Layer

5.1 VirusTotal Integration (Rules 87101–87105)

File-Hash-Lookup bei Datei-Erstellung. Workflow:

  1. FIM monitort C:\fim-test\
  2. File-Hash (SHA256) extrahiert
  3. VT-API abgefragt
  4. Result eskaliert zu Alert
Rule ID Level Bedingung Beschreibung
87101 3 VT-API Error Anfrage fehlgeschlagen (Rate-Limit, Key-Error)
87102 0 0 Detektionen File bekannt, aber von keinem Hersteller als Malware flagged
87103 5 Unbekannter Hash VT hat diese Hash noch nie gesehen
87105 14 1+ Detektionen Malware erkannt! Eskalation zu Critical

5.2 Windows Defender — Events 1116, 1117

Event ID Level Beschreibung
1116 13 Malware erkannt (Detection-Event)
1117 14 Malware-Aktion durchgeführt (Quarantine, Entfernung)

5.3 FIM — File Integrity Monitoring

Scope: realtime auf C:\fim-test\

  • Datei erstellt: Alert + VT-Check (T1105)
  • Datei geändert: Audit-Log-Eintrag (T1565)
  • Datei gelöscht: Warning-Alert (T1485)
  • Berechtigung geändert: Alert wenn verdächtig (T1222)

5.4 WEF Pipeline — Windows Event Forwarding

Domain Controller Events via Windows Event Forwarding (WEF) zu WEC01.

DC01 (nexora.example, 10.99.99.10) ↓ WEF Client Security Channel (EventID 4768, 4769, 4720–4767) ↓ WEC01 (10.99.99.11) → Wazuh Agent → Wazuh Manager ↓ local_rules 101200–101399 (Kerberoasting, DCSync, Golden Ticket, etc.)
Events von DC01: 4625 (Logon Failure), 4624 (Success), 4768/4769 (Kerberos TGT/TGS), 4662 (Directory Service Access), 4720–4740 (Account Management), 5136 (GPO Changes)

Suspicious PowerShell Hunt

T1059.001

Erkennt -EncodedCommand, -enc Parameter. Flaggt verdächtige Parent-Prozesse (WINWORD, EXCEL, OUTLOOK).

OPNsense Multicast Review

FP-Review

Filtert lokales Multicast-Rauschen (224.0.0.0/24). Kennzeichnet mDNS, Bonjour, SSDP als Low-Risk.

RDP Exposure Hunt

T1021.001

Prüft Port 3389 (TCP). Häufiger Initial-Access-Vektor. Empfehlung: VPN/MFA Requirement.

Persistence Hunt

T1547.001

Enumerer Run-Keys, Scheduled Tasks, Services, Autoruns. Flaggt verdächtige Binär-Pfade (%APPDATA%, %TEMP%).

Failed Logon Hunt

T1110

Aggregiert fehlgeschlagene Logons. Erkennt Brute Force (>8 in 120s, gleiche IP/Account) und Password Spray (>5 gegen mehrere Accounts).

DNS Tunneling Hunt

T1071.004

Analysiert Zeek DNS Logs. Berechnet Entropy, flaggt lange Queries (>100 Zeichen) zu seltenen Domains.

Scheduled Tasks Hunt

T1053.005

Query schtasks /query. Filtert Tasks mit PowerShell -w hidden oder -enc.

Services Hunt

T1543.003

Enumerer Services, prüft Binary-Pfade auf ungewöhnliche Ordner. Flaggt unsignierte Binaries.

Autoruns Hunt

T1547.001

Prüft Run-Keys, Startup-Ordner. Flaggt neu hinzugefügte Einträge mit verdächtigen Pfaden.

Remote Access Tools Hunt

T1219

Matched gegen RMM-Signaturen: AnyDesk, TeamViewer, ScreenConnect, ngrok. Kann legitim sein — muss validiert werden.

8.2 Neue Regel hinzufügen

  1. Bereich identifizieren: Welche Kategorie? (FileCreate, Registry, etc.)
  2. Nächste freie ID: Höchste ID im Bereich + 1
  3. XML schreiben: Wazuh-Rule mit <if_sid>, <field>, <mitre>
  4. Testen: Manager restart, manueller Test-Event, Match überprüfen
  5. Dokumentieren: Changelog, Commit

8.3 False Positive Handling

Golden Rule: Niemals global suppressieren. Stattdessen:
  • Schreibe Scoped FP-Exception (nur für Host/User)
  • Nutze Aggregation statt Blacklisting
  • Dokumentiere die Ausnahme-Begründung
