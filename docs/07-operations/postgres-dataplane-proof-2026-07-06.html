Code-Fix aus dem Proof

Der Lauf hat einen echten Messluecken-Befund gezeigt: Timeout-Fehler innerhalb eines transaktionalen client.query-Pfads wurden bisher nicht auf soc_db_query_timeouts_total gezaehlt. Das wurde direkt behoben.

  • backend/src/correlation/CorrelationMutationService.js: transaktionale Query-Funktion instrumentiert.
  • backend/tests/correlationMutationService.test.js: Regressionstest fuer Timeout-Zaehler hinzugefuegt.

Reproduzierbarkeit

  • node backend/scripts/loadtest/postgresProductionProof.js
  • node dataplane/scripts/outboxBacklogProof.js

Beide Skripte laufen gegen echte Postgres-Instanzen. Fuer den finalen Go-Live-Block sollten dieselben Laeufe zusaetzlich auf der echten Zielumgebung mit deren realen CPU-/RAM-/Netzbedingungen gefahren und archiviert werden.
