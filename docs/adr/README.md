# Architecture Decision Records (ADRs)

This folder contains all Architecture Decision Records documenting major decisions in the system design.

## Contents

- **[decisions.md](./decisions.md)** - Complete ADR collection
  - All architectural decisions (ADR-001 through ADR-040)
  - Decision rationale and context
  - Accepted, proposed, deprecated, and superseded decisions
  - Cross-references to implementation details

## ADR Categories

The decisions cover:

- **Authentication & Security** (ADR-009, ADR-017, ADR-019, ADR-022 to ADR-025, ADR-038)
- **AI / ML / Knowledge Systems** (ADR-014, ADR-016, ADR-018, ADR-030, ADR-039)
- **Data Model & Persistence** (ADR-005, ADR-008, ADR-013, ADR-014, ADR-015, ADR-030 to ADR-033)
- **Architecture & Patterns** (ADR-001, ADR-002, ADR-003, ADR-004, ADR-006, ADR-007, ADR-028, ADR-035, ADR-036)
- **Integration & External Systems** (ADR-010, ADR-011, ADR-012, ADR-016, ADR-018, ADR-026, ADR-027, ADR-037)
- **Operations & Deployment** (ADR-018, ADR-020, ADR-021, ADR-029, ADR-034)

> **Pending ADRs:** newer topics may still need an ADR entry - e.g. SAML, Zero-Trust-Implementierungsdetails, Multi-tenancy, SOAR bidirectional sync, konkrete ML-Implementierungs-/Promotionsregeln.
